# React Components Folder (`src/components`)

This folder contains the UI components:
- `Header.jsx`: Main application banner and companion status.
- `ModelStatusBanner.jsx`: Local model loading indicator & download progress.
- `ChatMessageList.jsx`: High-contrast accessible conversation feed.
- `MessageItem.jsx`: Individual chat message bubble with copy & speech controls.
- `ChatInput.jsx`: High-contrast input bar with voice button and image OCR upload.
- `QuickActions.jsx`: Accessible quick prompt buttons.
